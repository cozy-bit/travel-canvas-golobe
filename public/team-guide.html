🌿 2. Пошаговая инструкция по работе с Git и GitHub

Все работают через персональные ветки! Никто не пушит напрямую в ветку main.

1 Клонирование репозитория на свой компьютер

Откройте терминал (Git Bash / VS Code) и выполните:

git clone https://github.com/cozy-bit/travel-canvas-golobe.git cd travel-canvas-golobe

2 Установка зависимостей проекта

npm install

3 Создание своей ветки (Branch)

Каждый создаёт ветку под свою задачу:

# Для Кибриё: git checkout -b feature/hotel-flow # Для Толибова: git checkout -b feature/account-flow

4 Запуск локального сервера разработки

npm run dev

Проект откроется по адресу: http://localhost:5173

5 Сохранение работы (Commit)

git status git add . git commit -m "feat: complete hotel booking card design"

6 Отправка ветки в GitHub

git push -u origin НАЗВАНИЕ_ВАШЕЙ_ВЕТКИ

7 Создание Pull Request (PR)

Перейдите на страницу репозитория в GitHub, нажмите "Compare & pull request", напишите краткое описание сделанной работы и отправьте запрос тимлиду (Амирхону) на проверку и слияние.

💡 4. Инструкции разработчикам

📌 Инструкция для Кибриё:
• Ты работаешь с React + Tailwind CSS v4.
• Твои страницы: src/pages/hotels/HotelsPage.jsx, src/pages/auth/LoginPage.jsx, src/pages/auth/SignUpPage.jsx.
• Используй готовые UI компоненты: import Button from '../../components/ui/Button', Input, Checkbox.
• Все фото отелей уже лежат в src/assets/images/hotels/, а фото для входа в src/assets/images/auth/.
📌 Инструкция для Толибова:
• Ты работаешь с React + Чистый модульный CSS (без Tailwind).
• Твой единственный CSS файл: src/pages/account/Account.module.css.
• Твой компонент: src/pages/account/AccountPage.jsx.
• Чтобы применить стиль, пиши в JSX: <div className={styles.myClassName}>.
• Твои стили изолированы, поэтому ты можешь свободно писать любые свойства в CSS и не переживать, что сломаешь другие страницы!

🌿 2. Дастури қадам ба қадам оид ба Git ва GitHub

Ҳар як нафар дар шохаи (branch) шахсии худ кор мекунад. Ҳеҷ кас мустақиман ба шохаи main файл намефиристад!

1 Клон кардани лоиҳа ба компютер

Терминалро (Git Bash ё VS Code) кушоед ва фармонро иҷро намоед:

git clone https://github.com/cozy-bit/travel-canvas-golobe.git cd travel-canvas-golobe

2 Насб кардани китобхонаҳо (Dependencies)

npm install

3 Сохтани шохаи нав (Branch)

Ҳар як шахс шохаи худро месозад:

# Барои Кибриё: git checkout -b feature/hotel-flow # Барои Толибов: git checkout -b feature/account-flow

4 Оғоз кардани лоиҳа (Local Server)

npm run dev

Дар браузер кушоед: http://localhost:5173

5 Сабти тағйиротҳо (Commit)

git status git add . git commit -m "feat: complete hotel page cards"

6 Фиристодани шоха ба GitHub (Push)

git push -u origin НОМИ_ШОХАИ_ШУМО

7 Кушодани Pull Request (PR)

Ба вебсайти GitHub равед, тугмаи "Compare & pull request"-ро пахш кунед, шарҳи кӯтоҳ нависед ва ба тимлид (Амирхон) барои тафтиш ва ҳамроҳкунӣ ирсол кунед.
